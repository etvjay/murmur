Offline payments don't need another promise. They need a confirmed transaction.

Many projects say private money can move without a network. Murmur moves a real shielded Zcash transaction and a sealed note between devices, and the payment confirms on chain when someone reconnects. Every number on this page comes from a log in the project's evidence folder.

How it works

Five steps from a request to a confirmed payment.

  1. 1

    The merchant shares an address

    A receiving address for the payment and a public key for sealed notes.

  2. 2

    The payer builds it offline

    The wallet creates, proves and signs a shielded transaction with the network cut.

  3. 3

    It moves device to device

    The raw transaction and a sealed note pass to nearby devices. They forward the note without being able to read it.

  4. 4

    Whoever reconnects broadcasts

    The first device with internet submits the transaction once. Duplicates are dropped.

  5. 5

    It confirms on chain

    The payment is mined and the merchant reads the sealed receipt.

From a cut network to block 4,550,000

Two runs, both logged. One proves the transaction can be built offline. The other proves it can cross the carrier and confirm on chain.

Run A: built with the network cut

The build ran inside a network namespace with no connection. A lookup of the wallet server failed there first, as required. Then every step of the transaction build succeeded.

  • create
  • prove
  • sign
  • combine
  • extract
  • Raw transaction20,986 bytes, unified-address recipient
  • BroadcastNo. This run stops before broadcast by design.
  • Log folderevidence/03-acceptance-a

Run B: across the carrier and onto the chain

A payer process built the transaction and sent it with a sealed receipt. A separate gateway process received both, broadcast the transaction once, and sent back a sealed acknowledgement. Both processes ran on one machine over UDP loopback, so this run did not use a radio.

Reproduce

The carrier has no dependencies and needs Node 18.3 or newer. Run these from the project folder.

node --test test/*.test.js
node cli.js listen --port 47001 --identity ~/a.json --peer HOST:47002 --ack
node cli.js msg --port 47002 --recipient-pub <hex> --peer HOST:47001 --identity ~/b.json --text "hello"
